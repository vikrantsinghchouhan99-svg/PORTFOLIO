# VIKRANT — THE SERIES

A cinematic, streaming-inspired portfolio for **Vikrant Singh Chouhan**: Full Stack Java Developer and BCA Student.

## 🚀 Tech Stack

- **Framework:** React 18 + TypeScript + Vite
- **Styling:** Tailwind CSS 4
- **Animations:** Framer Motion
- **Smooth Scroll:** Lenis

## 📦 Features

- **Cinematic Opening Titles:** A Chouhan Original studio intro
- **Profile Selector:** "Who's watching?" customizable viewers (Vikrant, Recruiter, Developer, Creative)
- **Originals:** Featured real-world projects with Live Demos and GitHub links
- **Journey / Seasons:** Academic foundation, BCA, intensive Full Stack Java training at AU Academy & Infotact Solutions
- **Certifications & Moments:** AU Academy, Infotact Solutions, RSCIT (87% Distinction)
- **The Full Story:** Interactive on-screen resume viewer and PDF download
- **Direct Connect:** Quick contact channels for Email, Phone, GitHub, and LinkedIn

## 🛠 Local Development

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```
